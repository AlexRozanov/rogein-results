Только **Android**. Сборка ставится из личного кабинета, без Google Play.

## Установка

1. Откройте на телефоне [Приложение](/admin/app) (нужен вход в кабинет).
2. Нажмите **Скачать APK**.
3. Разрешите установку из этого источника, если Android спросит.
4. Откройте скачанный файл и установите SFR Reader.

Удобно: на странице «Приложение» есть QR — отсканируйте его камерой телефона, войдите в кабинет и скачайте APK.

## Обновление

Обновления ставятся **поверх** текущей версии. Старты, очередь чипов и настройки на телефоне **не стираются**.

Если система предлагает удалить старое приложение — не соглашайтесь: нужна установка поверх той же подписи (командный ключ клуба).

## Кому доступно

Страница и файл APK видны сотрудникам с учётной записью на сайте. Гостям без входа ссылка не отдаёт файл.
