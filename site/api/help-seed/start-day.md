Как подготовить телефон к конкретному старту.

## 1. Настройки публикации

**Ещё → Публикация:**

1. **Адрес API** — корень сайта, как в браузере (например `https://malahit-sprint.ru`), без порта `:18790`.
2. **Токен публикации** — выдаёт владелец (раздел Online в кабинете).
3. Сохраните доступ.

Адрес и токен на телефоне хранятся между стартами.

## 2. Взять старт с сайта

Кнопка **«Взять с сайта»** в публикации (и похожий шаг после нового старта):

- загружается список анонсов из календаря сайта;
- по выбору подставляются **название**, **дата** и **slug**.

Так меньше ошибок, чем вводить slug вручную. На компьютере то же самое: Настройки → Публикация → «Взять с сайта».

## 3. Протокол и дистанции

### Ориентирование

- **Протокол → Загрузить → Пакет с сайта** — если судья отправил пакет с компьютера (протокол + дистанции + карта).
- Или по USB / CSV / XML, если пакет на сайте ещё не выложен.

### Рогейн

- **Пакет с сайта** — протокол, форматы, группы, легенды, карта.
- Нужны те же адрес, токен и slug.

Пакет на сайте **не** появляется в календаре сам по себе: его кладёт компьютер кнопкой «Отправить пакет на телефон (сайт)».

## 4. Проверка перед стартом

- Один и тот же **slug** на всех телефонах.
- Если нужен обмен — см. раздел «Обмен между телефонами».
- Если нужен live для зрителей — настроенная публикация и один издатель online.
