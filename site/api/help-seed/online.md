Как связать телефон (и компьютер) с сайтом для live-результатов и пакета старта.

## Где взять адрес и токен

Владелец клуба: кабинет → **Online / live** — адрес API, токен (показать / скопировать) и краткая инструкция.

Токен знают только владельцы. Его не публикуют в чатах без нужды.

## На телефоне

**Ещё → Публикация:**

1. Вставьте адрес API и токен → сохраните.
2. Укажите **slug** и название (или «Взять с сайта»).
3. Включите отправку online, если выключена.
4. При полевом обмене live шлёт только **хост** (LAN) или **издатель** (облако). Не включайте издателя на двух телефонах сразу.

Проверка: после финиша / «Отправить online» страница `/live/<slug>` обновляется.

## Пакет на телефон через сайт

1. На компьютере: Настройки → Публикация → заполнены адрес, токен, slug.
2. **Отправить пакет на телефон (сайт)**.
3. На телефоне: **Протокол → Загрузить → Пакет с сайта**.

Сайт сверяет **slug** и токен; вид старта (рогейн / ориентирование) должен совпадать с пакетом.

## На компьютере

Настройки → «Публикация на сайт»: тот же адрес и токен сохраняются в данных программы и не сбрасываются при завершении старта.
