# Как настроить обмен между телефонами (для судей)

Пошаговая инструкция без технических подробностей. 

Только **Android**. На всех телефонах одно и то же приложение Rogein Chip.

### Установка и обновление приложения

Сборка только из личного кабинета: **https://malahit-sprint.ru/admin/app** (нужен вход; в меню — «Приложение»).

1. Войдите в кабинет на телефоне → «Приложение» → «Скачать APK».
2. Разрешите установку из этого источника, если Android спросит.
3. Обновления ставятся **поверх** — старты и очередь на телефоне не стираются.

Не нужен Google Play. Доступ к странице и файлу — у сотрудников с учёткой на сайте.

---

## Словарь на минуту

| Как говорим | Что это |
| --- | --- |
| **Wi‑Fi** | Беспроводная сеть рядом: роутер или «раздача интернета» с телефона. Между телефонами на старте данные ходят именно так. |
| **LTE / мобильный интернет** | Интернет через SIM-карту оператора. Нужен, чтобы отправить результаты на сайт. |
| **Хост** | Один главный телефон: принимает данные от остальных и хранит общий журнал старта. |
| **Клиент** | Остальные телефоны: шлют свою выдачу/финиш хосту и забирают чужие данные. |
| **Пароль обмена** | Короткий код (4–6 символов), общий для всех телефонов на этом старте. Это не пароль Wi‑Fi и не токен сайта. |
| **Slug** | Имя старта для сайта (как в ссылке `/live/...`). Должен совпадать на всех телефонах. |
| **Online / live** | Публикация результатов на сайт для зрителей. Отдельно от обмена между телефонами. |
| **Издатель online** | Телефон, которому разрешено слать снимок на сайт. В локальной сети это обычно хост; в облаке — тот, у кого включено «Издавать online». |

**Главное правило:** обмен между телефонами и отправка на сайт — разные вещи. Обмен может работать без интернета. Сайт — только когда есть LTE (или интернет у роутера).

В приложении пути разделены: **обмен идёт по Wi‑Fi**, **сайт — по мобильному интернету**, если он есть. В статусе обмена можно увидеть подписи вроде `· Wi‑Fi` и `· LTE`.

## Что выбрать

| Ситуация | Режим в приложении |
| --- | --- |
| Один телефон, без обмена с другими | **Выкл** |
| Несколько телефонов, нет роутера, лес/коридор | **Локальная сеть**, хост сам раздаёт Wi‑Fi |
| Есть карманный роутер / Wi‑Fi в машине | **Локальная сеть**, все в Wi‑Fi роутера |
| Раздать Wi‑Fi нельзя, но у всех есть интернет | **Облако** |

На одном старте — **один** режим. Не смешивать «локальную сеть» и «облако».

Где в приложении: **Ещё → Обмен** (полевой обмен).  
Публикация на сайт: **Ещё → Публикация** (адрес сайта, токен, slug, название).

Перед стартом на всех телефонах: один и тот же **slug** и (для сайта) адрес + токен публикации.

---

## Режим «Выкл»

Обмена между телефонами нет. Один аппарат работает как обычно.

1. **Обмен** → режим **Выкл** → **Сохранить** (если обмен был запущен — сначала **Стоп**).
2. При необходимости настройте **Публикацию** и отправляйте online с этого же телефона.

---

## Режим «Локальная сеть» — телефон раздаёт Wi‑Fi (без роутера)

Подходит, когда нет роутера: один телефон становится и «точкой Wi‑Fi», и хостом обмена.

```
[телефон-хост]  раздаёт Wi‑Fi  +  хост обмена
       ↑
  другие телефоны (клиенты)
```

### А. Телефон-хост (главный)

#### В системе Android

1. Откройте настройки телефона → **Точка доступа и модем** / **Режим модема** (название зависит от марки).
2. Включите **Wi‑Fi точку доступа**.
3. Задайте имя сети, например `Rogein-finish`, и **пароль Wi‑Fi** (это пароль сети, не пароль обмена в приложении).
4. Подключите **пауэрбанк** — раздача сильно сажает батарею.
5. Желательно не блокировать экран надолго; приложение само держит уведомление, пока хост запущен.

Если с этого же телефона нужен online на сайт — оставьте **мобильный интернет (LTE) включённым**. Приложение постарается слать сайт по LTE, а обмен — по своей точке Wi‑Fi.

#### В приложении Rogein

1. **Публикация** (если нужен сайт): адрес сайта, токен, slug, название старта. Сохраните.
2. **Обмен** → **Локальная сеть** → роль **Хост**.
3. **Имя аппарата** — понятное, например `Стол-судьи`.
4. **Пароль** — придумайте 4–6 символов (латиница/цифры), запомните. Его введут все клиенты.
5. Нажмите **Запустить**.
6. На экране появятся **IP** (часто что-то вроде `192.168.43.1`) и **QR**. Клиенты сканируют QR или вводят этот IP.

Статус вроде `хост · HTTP+WebSocket :8787 · Wi‑Fi+LTE` — нормально: порт 8787 слушает хост, пути сетей подключены.

**Не выключайте** точку доступа и не нажимайте **Стоп**, пока идёт старт (кроме смены режима по договорённости).

### Б. Телефоны-клиенты (выдача, финиш, …)

#### В системе Android

1. Wi‑Fi → сеть хоста (`Rogein-finish` и т.п.) → пароль **Wi‑Fi** (тот, что в точке доступа).
2. Если телефон пишет «нет интернета» и отключается:
   - зайдите в свойства этой сети;
   - включите что-то вроде **«Не переключаться на мобильную сеть автоматически»** / **оставаться в этой сети** (формулировки разные у Samsung, Xiaomi, Pixel…);
   - при необходимости отключите «избегать слабых сетей» / «умные переключения».
3. Мобильный интернет клиентам для **обмена** не обязателен. Для своего live — обычно не шлют (шлёт хост).

#### В приложении Rogein

1. Тот же **slug** старта, что у хоста (в публикации / настройках события).
2. **Обмен** → **Локальная сеть** → роль **Клиент**.
3. Тот же **пароль обмена**, что на хосте.
4. **Канал связи**: можно оставить **Авто** (сначала быстрый WebSocket, при сбое — опрос).
5. **IP хоста** — с экрана хоста или кнопка сканера QR.
6. Дождитесь зелёной строки вроде «Хост отвечает» → **Запустить**.

Если хост пропал надолго — на **одном** клиенте можно **Стать хостом** (старый хост должен быть выключен). Два хоста сразу нельзя.

## Режим «Локальная сеть» — карманный роутер

Удобнее, если роутер есть: сеть не зависит от одного телефона.

```
          [роутер]
         /   |    \
    хост   выдача  финиш
```

Обмен — по Wi‑Fi роутера. Сайт (live) — по **LTE того телефона, который издаёт** (обычно хост), даже если у роутера интернета нет.

### Роутер

1. Включите отдельную сеть старта (не «гостевую» с изоляцией клиентов, если есть такой режим — выключите isolation).
2. Запомните имя Wi‑Fi и пароль роутера.
3. Лучше диапазон **2.4 ГГц** (дальше пробивает стены/лес у машины).
4. Питание роутера — розетка или пауэрбанк.

### Все телефоны — система

1. Подключитесь к Wi‑Fi **роутера** (не к раздаче другого судьи).
2. Если Android норовит отключить Wi‑Fi «без интернета» — закрепите сеть вручную (см. выше у клиентов).
3. На телефоне-хосте (издателе live) включите **LTE**.

### Хост — приложение

1. **Публикация**: сайт, токен, slug, название.
2. **Обмен** → **Локальная сеть** → **Хост** → пароль обмена → **Запустить**.
3. Покажите клиентам **IP из приложения** (это IP телефона в сети роутера, не обязательно `192.168.43.1`) или QR.

### Клиенты — приложение

Как в сценарии без роутера: **Клиент**, тот же пароль, IP/QR хоста, **Запустить**.

### Online при роутере

- Результаты на сайт шлёт **хост** (в публикации включена отправка).
- На хосте в **Обмене** блок **«Куда слать online»**:
  - **Авто** (по умолчанию) — если у Wi‑Fi роутера есть интернет, шлёт через Wi‑Fi; если нет — через LTE.
  - **LTE** — всегда мобильный интернет.
  - **Wi‑Fi** — всегда через роутер (нужен интернет у роутера).
- Обычно достаточно **Авто**. Переключать вручную стоит, если авто ошиблось (роутер «как будто с интернетом», а сайт не открывается — поставьте LTE). Менять переключатель можно **на лету**, хост перезапускать не нужно — следующий live уже пойдёт выбранным путём.
- Клиенты в LAN online сами не шлют — иначе два снимка затрут друг друга.

## Режим «Облако»

Wi‑Fi между телефонами не нужен. Нужен **интернет у каждого** (обычно LTE) и настроенная **Публикация** (адрес сайта + токен + slug).

Журнал операций хранится на сайте; каждый телефон забирает чужие операции и считает результат у себя. Live на сайт шлёт только **издатель**.

### На каждом телефоне — система

1. Рабочий мобильный интернет (или любой интернет до сайта).
2. Wi‑Fi для обмена не требуется (можно быть в любой сети с доступом в интернет).

### На каждом телефоне — приложение

1. **Публикация**: один и тот же адрес сайта, токен, **одинаковый slug**.
2. **Обмен** → **Облако**.
3. **Пароль обмена** — один на всех (первый телефон «создаёт» сессию на сайте; остальные — с тем же паролем).
4. **Издавать online** — по умолчанию **выкл**. Включите **только на одном** телефоне (кто будет слать live). Если роль занята — приложение предложит перехватить.
5. Дождитесь «Сайт отвечает» → **Запустить**.

Статус вроде `связано · облако · LTE` — обмен с сайтом идёт.

**Не включайте** «Издавать online» на двух телефонах сразу — снимки на сайте будут затирать друг друга. Сайт помнит одного издателя; смена — через перехват с подтверждением.

---

## Публикация на сайт (все режимы)

Экран **Ещё → Публикация**:

1. **Адрес API** — корень сайта, как в браузере (например `https://malahit-sprint.ru`).
2. **Токен** — выданный для машины/клуба.
3. **Slug** и **название** старта.
4. При необходимости галка «публиковать результаты» (на клиенте LAN её может не быть — шлёт хост).

Проверка: кнопка проверки сайта / «отправить сейчас» после того, как есть что публиковать.

В режиме **локальная сеть** live с клиента не уходит.  
В режиме **облако** live только у издателя.

## Частые проблемы

| Симптом | Что проверить |
| --- | --- |
| Клиент не видит хост | Тот же Wi‑Fi? Верный IP/QR? Пароль **обмена** совпадает? Хост запущен? На точке доступа хост = тот, кто раздаёт сеть. |
| Wi‑Fi есть, но «нет связи» | Android мог отключить сеть без интернета — закрепите сеть. Обновите статус/IP на хосте. |
| Обмен есть, сайт не обновляется | LTE на издателе/хосте? Токен и slug? В облаке — включено «Издавать online» только у одного? |
| «Неверный пароль» / 401 | Пароль обмена; в облаке ещё и токен сайта. |
| Другой slug | На всех телефонах один slug текущего старта. |
| Два хоста / два издателя | Оставьте одного. Второй — Стоп или выключить «Издавать online». |
| Хост «уснул» | Не сворачивать насмерть; смотреть уведомление keep-alive; пауэрбанк. |

---

## Краткий чеклист перед стартом

1. Выбран **один** режим на всех телефонах.  
2. Один **slug**, один **пароль обмена**.  
3. LAN: ровно **один хост**; клиенты в его Wi‑Fi (или Wi‑Fi роутера).  
4. Облако: у всех интернет; **один** издатель online.  
5. Если нужен сайт — на издателе работают LTE + публикация.  
6. Хост/издатель на питании; клиентам при «Wi‑Fi без интернета» — закрепить сеть в настройках Android.
