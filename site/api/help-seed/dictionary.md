Короткие определения — ими пользуются все инструкции ниже.

| Как говорим | Что это |
| --- | --- |
| **Wi‑Fi** | Беспроводная сеть рядом: роутер или «раздача» с телефона. Между телефонами на старте данные ходят по Wi‑Fi. |
| **LTE** | Мобильный интернет через SIM. Нужен, чтобы отправить результаты на сайт. |
| **Хост** | Один главный телефон: принимает данные от остальных и хранит общий журнал старта. |
| **Клиент** | Остальные телефоны: шлют выдачу/финиш хосту и забирают чужие данные. |
| **Пароль обмена** | Короткий код (4–6 символов) для всех телефонов на этом старте. Это не пароль Wi‑Fi и не токен сайта. |
| **Slug** | Идентификатор старта для сайта (как в ссылке `/live/...`). Должен совпадать на всех телефонах. |
| **Online / live** | Публикация результатов на сайт для зрителей. Отдельно от обмена между телефонами. |
| **Издатель online** | Телефон, которому разрешено слать снимок на сайт. |
| **Пакет** | Протокол, дистанции/форматы и карта, которые компьютер кладёт на сайт; телефон скачивает по slug и токену. |

**Главное:** обмен между телефонами и отправка на сайт — разные вещи. Обмен может работать без интернета. Сайт — только когда есть LTE (или интернет у роутера).
